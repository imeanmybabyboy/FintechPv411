MetaMask - плагін для браузерів, який містить бібліотеку коду для роботи з криптомережами та смарт-контрактами, а також візуальні інструменти для їх контролю, у т.ч. стан гаманця.
-- встановлюється як плагін, обліковий запис може бути підключений від інших обліковок

Налаштовуємо роботу з локальною мережею Hardhat
відкриваємо термінал, переходимо до /evm, запускаємо
> npx hardhat node
У плагіні відкриваємо налаштування мереж
(burger) -> Networks
[Add a custom network]
Name: Hardhat
Default RPC URL: (add URL) http://127.0.0.1:8545
Chain ID: 31337
Currency symbol: ETH

Підключаємо гаманець від Hardhat до MetaMask
- копіюємо з консолі запуску Hardhat приватний ключ довільного облікового запису
- у MetaMask відкриваємо Accounts (Click to Account1)
- натискаємо Add Wallet
- вибираємо Import an account via private key
- вставляємо скопійований ключ
- відкриваємо створений гаманець (обліковку)

Створюємо застосунок фронтенду на базі React
- відкриваємо новий термінал в корені проекту
> npm create vite@latest
- встановлюємо бібліотеку ethers
> cd app
> npm i ethers
- подальші інструкції в проекті (App.tsx)
